- Count safely avoided reading and all routing/retry overhead. Keep exact common-tokenizer guide counts, observable serialized-input proxies, and provider-native usage distinct. Hidden wrappers and unobserved downstream execution stay unknown; a regex word count is a toy unit unless the declared question actually concerns words.
- Report counts/denominators, safe coverage, raw/enforced unsafe skips, invalid/missing outcomes, p50/p95 latency, cost, repeat stability and resource usage. Separate cold model load, request latency, deterministic bypasses and end-to-end time. Repeats do not increase unique sample size.
